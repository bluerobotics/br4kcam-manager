# Endpoints that clients depend on. `cargo test` fails if any of these disappear.
#
# Append new endpoints when they become public. Never remove or edit a line: a
# client somewhere still calls it. See README.md.
#
#   HTTP <method> <path>   a route on the HTTP server
#   WS <method> <path>     a request routed over the WebSocket (`WsRequest`)
#   EVENT <name>           an event pushed over the WebSocket (`WsEvent.event`)
